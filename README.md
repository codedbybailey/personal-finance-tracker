### 🌷 about this project

Hi! Welcome to my Personal Finance Tracker! ♡

This is a beginner-friendly web application I'm
building to practice my frontend development skills
while learning how to create interactive applications.

My goal is to make tracking income, expenses,
and savings simple, organized, and easy to understand.

I'm building this project from scratch as part
of my programming journey!

---

### 💕 planned features

- ♡ Add income and expenses
- ♡ Organize transactions into categories
- ♡ Calculate total balance
- ♡ View transaction history
- ♡ Delete transactions
- ♡ Save transactions using localStorage
- ♡ Visualize spending with charts
